LPIC-1（およびLinuC-1）は、Linuxサーバーの日常運用ができることを示す資格です。2つの試験に分かれており、前半でシステムアーキテクチャ・パッケージ管理・コマンド操作・ファイルシステム、後半でシェルとスクリプト、ユーザー管理、システムサービス、ネットワーク、セキュリティを扱います。特徴は「コマンドとオプションを直接問われる」ことで、選択式に加えて入力形式の設問もあります。実機（仮想マシンやコンテナ）を触りながら覚えるのが結局いちばん速い試験です。

起動の流れは、電源投入からBIOSまたはUEFI、ブートローダ（GRUB2）、カーネル、初期化プロセスという順で押さえます。現在の主流はsystemdで、サービスの操作は systemctl start/stop/enable/status、起動状態の目標はターゲット（multi-user.target、graphical.target など）で表されます。ログの確認は journalctl が基本で、-u でユニット指定、-f で追従表示です。デバイスの認識状況は lsblk、lspci、lsusb、dmesg といったコマンドで確認します。

パッケージ管理は、Debian系とRed Hat系の2系統を対比で覚えるのが効率的です。Debian系は dpkg（単体パッケージ）と apt（依存関係の解決とリポジトリ）、Red Hat系は rpm と dnf/yum が対応します。インストール・削除・検索・インストール済み一覧といった操作を、両系統で言えるようにしておきます。共有ライブラリの依存確認には ldd、キャッシュの更新には ldconfig を使います。

コマンド操作では、パイプとリダイレクトの理解が土台です。標準出力は1、標準エラー出力は2で、2>&1 でエラーを標準出力にまとめられます。テキスト処理は grep（検索）、sed（置換）、awk（列の抽出と集計）、cut、sort、uniq、wc、head/tail の組み合わせが定番です。正規表現は基本正規表現と拡張正規表現の違いも問われます。プロセス操作は ps、top、kill、jobs、bg/fg、nohup、優先度の nice/renice を押さえます。

ファイルシステムでは、FHSに基づくディレクトリの役割（/etc は設定、/var は可変データ、/usr はプログラム、/tmp は一時ファイル）を覚えます。パーミッションは読み4・書き2・実行1の合計で表し、chmod で変更、chown で所有者を変更します。特殊なビットとして、SUID・SGID・スティッキービットの意味は頻出です。リンクは、実体を共有するハードリンクと、パスを指すシンボリックリンクの違い、シンボリックリンクは別ファイルシステムやディレクトリにも張れることを押さえます。マウントは mount と /etc/fstab、確認は df と du です。

シェルとスクリプトでは、環境変数（export、PATH）、シェル変数との違い、エイリアス、シェルの設定ファイルの読み込み順を扱います。スクリプトは if / case による条件分岐、for / while によるループ、test（[ ]）による条件評価、$? による終了ステータスの確認が基本です。定期実行は cron（crontab -e、5つのフィールドは分・時・日・月・曜日）と、systemd のタイマーがあります。

ユーザー管理とシステムサービスでは、useradd/usermod/userdel、groupadd、passwd と、/etc/passwd・/etc/shadow・/etc/group の各ファイルの役割を押さえます。時刻同期、ログのローテーション（logrotate）、ローカルのメール転送の基礎も範囲です。ネットワークは、ip コマンドによるアドレス確認と設定、ping や traceroute による疎通確認、名前解決の設定（/etc/hosts、/etc/resolv.conf）、ss や netstat による待ち受けポートの確認が中心になります。セキュリティでは、SSHの公開鍵認証、sudo による権限委譲、パスワードの有効期限設定、不要なサービスを止めるという基本の考え方が問われます。
